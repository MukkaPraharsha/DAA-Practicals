# conclusion

Prim’s Algorithm was successfully implemented in Python to find the Minimum Spanning Tree (MST) of a weighted, undirected graph. It selects minimum-weight edges without forming cycles and connects all vertices with the minimum total cost.
Time Complexity (TC): O(ElogV)
Space Complexity (SC): O(V+E)
Here, (V) is the number of vertices and (E) is the number of edges, using an adjacency list and a min-heap.
