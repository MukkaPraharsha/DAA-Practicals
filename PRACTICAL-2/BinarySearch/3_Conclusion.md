# conclusion

Binary Search is an efficient searching algorithm that works only on sorted arrays. By repeatedly dividing the search space in half, it achieves an average and worst-case time complexity of O(log n), making it much faster than Linear Search for large datasets. It is widely used because of its speed and low memory usage in the iterative implementation.

Time Complexity
Best Case: O(1)
Average Case: O(log n)
Worst Case: O(log n)

Space Complexity: O(1)
